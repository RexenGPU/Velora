Privacy overview

Loaded over HTTPS

Favorites, settings and the vault stay on this device — no server, nothing uploaded.

Password vault

AES-GCM 256-bit

Master password never stored. Optional auto-login while unlocked.

Built like a browser, honest like a tool

Everything you need for daily browsing, with privacy as the architecture — not a marketing layer.

Zen-style vertical tabs

A slim sidebar that expands on hover with real site favicons. Content always adapts — nothing is ever covered.

One unified bar

Navigation, HTTPS indicator, hostname and window controls in a single top bar that adapts to what you're doing.

Real shortcuts

Ctrl+T new tab · Ctrl+W close · Ctrl+Tab cycle · / to search, or type an address to open it directly.

Encrypted vault

AES-GCM 256-bit with PBKDF2 (310k iterations). Your master password is never stored — it exists only in memory while unlocked.

Honest privacy tools

A URL inspector that shows what's actually observable, a browser checklist, and clear explanations — no fabricated scores.

A start page you own

Live clock, quick links with categories, any search engine you want (including your own), optional history — off by default.

Privacy-first, verifiably

Not claims — mechanics. Everything below is in the source.

No server. There is no Velora backend to send anything to. No account, no sync, no telemetry.

Only two things leave your device: search queries go directly to your chosen engine, and opening a link contacts that site. Optional site icons contact DuckDuckGo's icon service — and can be switched off.

Vault encryption: AES-GCM 256-bit, key derived from your master password with PBKDF2-SHA256. A forgotten master password cannot be recovered — by design.

History is opt-in and off by default. When enabled: local only, capped at 500 entries, excluded from backups, clearable anytime.

Restrictive CSP in production builds (default-src 'none') and zero third-party scripts — even on this page.
